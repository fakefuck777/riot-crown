RIOT Y2K — Dawn 主題安裝清單（Dark Y2K Luxury 全套）
================================================

A) 上傳 CSS（必備）
   Assets → 新增 riot-y2k-luxury.css → 貼上 repo 內同檔完整內容。

A2) 上傳 JS（必備：粒子 + 產品卡 chrome 反光）
   Assets → 新增 riot-y2k-runtime.js（與 repo 同檔）。

B) 上傳 Snippet
   Snippets → 新增 riot-y2k-fonts.liquid
   Snippets → 新增 riot-y2k-head.liquid（可選：一次載入 CSS + 字型 + vars + runtime）

C) 上傳 Sections（依序新增檔案）
   - riot-y2k-hero.liquid
   - riot-y2k-featured-collection.liquid
   - riot-y2k-countdown.liquid
   - riot-y2k-trust-strip.liquid
   - riot-y2k-symbol-marquee.liquid
   - riot-y2k-lowrise-banner.liquid（低腰感寬圖模組）
   - riot-y2k-product-callout.liquid（給「產品」模板用）

D) 全域載入（layout/theme.liquid 的 <head> 內，擇一）
   【推薦】{% render 'riot-y2k-head' %}
   【手動】{{ 'riot-y2k-luxury.css' | asset_url | stylesheet_tag }}
           {% render 'riot-y2k-fonts' %}
           （若未用 riot-y2k-head，請確保 hero / featured-collection 區塊內的 runtime 腳本仍存在）

E) 可選 — 主題色編輯器
   將 config/settings_schema_riot_y2k.fragment.json 陣列裡「第一個物件」併入 config/settings_schema.json 根陣列。
   併入後：若 <head> 用的是 `{% render 'riot-y2k-head' %}`，已內含 `riot-y2k-theme-vars`，不必重複加。
   若用手動載入（見 D），請在 <head> 再加：`{% render 'riot-y2k-theme-vars' %}`

F) 主題編輯器 / GitHub 首頁 JSON
   • 本 repo 提供 templates/index.json（僅 RIOT 區塊順序）。若你的 Dawn 已有首頁，請先備份 themes/.../templates/index.json 再合併或整檔替換。
   • 替換後請在後台「首頁」確認 Section 無報錯；collection 留空時會使用「所有商品」邏輯（見 riot-y2k-featured-collection.liquid）。
   • 手動：依 COPY_AND_PRODUCT_TIPS.txt 順序在編輯器加入各 Section。

F2) 主題編輯器（僅手動）
   首頁：依 COPY_AND_PRODUCT_TIPS.txt 建議順序加入各 Section。
   產品頁：Products → Default product → Add section → RIOT Y2K Product callout

G) card-product 報錯時
   打開 snippets/card-product.liquid 檔頭註解，對齊 {% render %} 參數名稱與你的 Dawn 版本。

H) Hydrogen 店（riotcrown 無頭）與本包無關；本包只作用在 Online Store 的 Dawn 主題。

I) 【緊急白屏/留白】請確認：
   • 不要刪除或整份覆蓋 Dawn 的 assets/base.css（會導致版面崩壞）。
   • riot-y2k-luxury.css 必須在 base.css「之後」載入（見 theme.liquid 註解）。
   • layout/theme.liquid 須有標準 viewport：`<meta name="viewport" content="width=device-width,initial-scale=1">`
   • 瀏覽器 Console 檢查：見下方「Console 檢查清單」。

Console 檢查清單（貼到 Console 執行或觀察）：
   • document.querySelector('link[href*="riot-y2k-luxury"]') 是否非 null（CSS 有載入）
   • 紅色報錯：Failed to load resource / MIME type / 404 on .css or .js
   • document.getElementById('MainContent') 是否存在、offsetHeight 是否 > 200
   • getComputedStyle(document.body).backgroundColor（是否仍為白/透明）
   • Shopify.designMode 若為 true，為主題編輯器預覽；請同時用手機實機預覽連結測試
